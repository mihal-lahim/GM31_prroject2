# GM31_prroject2

Visual Studio / C++20 / DirectX 11 の共通ゲームエンジンと、それを使う6つのアプリです。

| アプリ | 内容 | 文書 |
|---|---|---|
| WireAction | 主作品。おもちゃロボが300mの工場をワイヤーで登るタイムアタック | [wire-action.md](docs/games/wire-action.md) |
| SlowAction | 時間減速・吹き飛ばし・追撃のアクション試作 | [slow-action.md](docs/games/slow-action.md) |
| FpsGame | 一人称の射撃練習 | [fps-game.md](docs/games/fps-game.md) |
| BattingCenter | バッティングゲーム | — |
| ClassroomWalk | キャラクター移動・アニメーション・地形などの授業用サンプル | [classroom-walk.md](docs/games/classroom-walk.md) |
| ShaderGallery | シェーダー比較の授業用アプリと森の描画デモ | [shader-gallery.md](docs/games/shader-gallery.md) |
