# SlowAction — 時間減速アクション試作 v0.1

`SlowAction.vcxproj` は、時間減速・ダッシュ・吹き飛ばし・空中追撃の組み合わせを確かめるための試作です。

| 入力 | 動作 |
|---|---|
| WASD | カメラ基準の移動 |
| マウス | カメラ回転 |
| Shift 長押し | ダッシュ (方向転換に軽い慣性) |
| 左クリック 短押し / 長押し | 離した瞬間に通常攻撃 / 強攻撃 (0.25秒以上で強。強は出が遅く隙が長く、途中まではダッシュで抜けられない) |
| 右クリック 長押し | 時間減速 (敵側だけ0.35倍。ゲージを消費。敵の攻撃が当たる直前に発動するとジャスト減速になり、ゲージ回復と得点) |
| R / F1 / F2 / Esc | やり直し / 当たり判定表示 / 敵無敵(練習用) / 終了 |

通常攻撃は大剣の3段コンボです。攻撃の終わり際に次を押す(先行入力)か、終わってから0.3秒以内に押すと次の段へつながり、3段目は当たった敵を小さく吹き飛ばします(強攻撃より近く・低く・短い)。強攻撃・ダッシュ・猶予切れで1段目に戻ります。各段のクリップ上の区間と当たる瞬間は `assets/config/slow-gameplay.cfg` の `Combo*` で調整できます。

左クリックを0.25秒押し続けると溜めに入り、回転斬りの構えでその場に止まります。溜めている間は移動もダッシュもできず、向きだけ変えられます。離すと強攻撃が出ます。

強攻撃は体ごと1回転する横薙ぎ(`Akai_Strong.fbx`)で、クリップ上の区間・当たる瞬間・再生倍率は `StrongClip*` と `StrongPlaybackSpeed` で調整できます。

強攻撃で敵を吹き飛ばし、着地する前にもう一度当てると追撃になります。3段目で浮いた敵にも追撃できます。追撃はダメージが1多く、地上で殴り続けるより早く倒せます。追撃すると吹き飛び時間と壁反射回数が戻り、時間減速ゲージが回復します(減速中の回復は減速終了時にまとめて反映)。

敵は3種類です。シーンファイルでは `int Kind` (0〜2) で指定します。

| 型 | 色 | 特徴 |
|---|---|---|
| 近接 (0) | 人型(Mixamo) | 近づいて殴る。予兆(赤く光る)の間に横へ動けば避けられる。歩き・のけぞり(通常攻撃)・殴られて浮いて倒れる(吹き飛ばしと撃破)のモーション付き。吹き飛ばすと背中から落ちて、受け身の後に起き上がる。倒すと亡骸が倒れてから床へ沈む |
| 射撃 (1) | 紫 | 6〜12m の距離を保ち、照準線を出してから撃つ。弾は攻撃で打ち返せ、撃った敵へ戻って吹き飛ばす |
| 重量 (2) | 灰 | 通常攻撃ではひるまない。強攻撃2回で装甲が割れて打ち上がる(飛ぶ距離は短い)。殴りかかってくる予兆中に強攻撃を合わせると一撃で割れる |

当てるたびにコンボが伸び、5コンボごとに得点倍率が上がります(最大4倍)。最後のヒットから2.5秒(ワールド時間なので減速中は長くなる)で切れ、被弾でも切れます。
追撃・壁反射・打ち返し・撃破は大きく加点され、右上に表示されます。最高スコアと最大コンボはやり直しても残ります(アプリを終了すると消えます)。

ヒットストップ・画面揺れ・被弾した敵の白い点滅・効果音は、当たりの重さに合わせて段階的に強くなります。
効果音は `scripts/generate-slow-action-sounds.ps1`、モデルは `scripts/generate-slow-action-models.sh` で生成した仮素材です。

## 時間減速の演出

減速を「切り替わりの衝撃」「遅くなった世界」「その中で自分だけ速い」の3つで見せます(音は変えていません)。

- **画面**: ポストエフェクト `post-time-slow`(`shaders/post/timeSlowPS.hlsl`)を、減速の深さ(時間倍率から求めた0〜1)に合わせて掛けます。
  彩度を落として寒色へ寄せ(強い赤は彩度を残すので、敵の予兆は見落としません)、外周を暗くし、外周だけ弱く色をずらします。
  画面中央と HUD の文字が読めるよう、常に掛かる歪みは外周だけです。
- **衝撃波**: 発動すると画面中心から外へ、解除する(ゲージ切れの強制解除を含む)と外から中心へ、細い歪みの輪が走ります(0.35秒)。
- **ジャスト減速**: 成功した瞬間、画面が一瞬だけ反転してシアンに光ります(0.12秒)。
- **世界側の粒**: 闘技場に光の粒がうっすら漂います。粒と、敵・弾の火花・照準線・弾の軌跡はワールド時間(時間チャンネル1)で動き、
  減速中は宙でゆっくり漂って、消えるのも遅くなります。
- **プレイヤー側**: 減速中のダッシュと攻撃に青白い軌跡(ダッシュは体、攻撃は刃に沿う)が付きます。ジャスト減速の火花とともに
  実時間で消えるので、止まった世界の中で自分だけ速く動いて見えます。
- **画角**: 減速の深さに合わせて画角を5度狭めます。ダッシュで広がる画角にもそのまま重なります。

演出が何も無いとき(減速しておらず、衝撃波もフラッシュも無いとき)はポストエフェクトを外すので、通常時の描画は変わりません。
編集モード・やり直し・倒れたとき・シーンの終了では、ポストエフェクトと衝撃波・フラッシュを消します(撒いた光の粒は残り、寿命で消えます)。
衝撃波とフラッシュの時間は、ヒットストップとポーズの間は止まります。強さと時間は `slow.SlowFx*` と `slow.CameraSlowFovNarrowDegrees` で調整できます。

## 編集モード (F3)

F3 でゲームを止めて編集モードに入り、もう一度 F3 でその配置のまま再生に戻ります。

- 視点: 右ドラッグで見回す、WASD / Q・E で移動(Shift で加速)、ホイールで前後。
- 選択: 「階層」の一覧か、画面上の点をクリック。
- 編集: 「インスペクタ」で名前・位置・回転・スケール・各オブジェクトの公開値を変更。追加・複製・削除は「階層」から。
- 保存: 「保存」を押したときだけ `assets/scene/slow-stage.scene` へ書きます(ソース側と実行フォルダの両方)。保存せずに再生へ戻った変更は、アプリを終了すると消えます。

ステージの配置(床・壁・障害物・プレイヤー・敵)はこのシーンファイルが持っています。テキストなので直接書き換えることもできます。
新しい型を編集対象にするには、`GameObject::Reflect` で値を公開し、`Engine::ObjectTypeRegistry::Register` で登録します。

調整値は `assets/config/slow-gameplay.cfg` にまとめてあり、再コンパイルなしで変えられます。
調整値の一覧・既定値・説明は `include/games/slow/slowActionTuning.def` の1か所にあり、項目を足す・消すときはこのファイルに1行書くだけです。
WireAction(`wireGameplayTuning.def`)と BattingCenter(`battingGameplayTuning.def`)も同じ方式です。
設定ファイルに一覧に無いキー(書き間違い)があると、画面左上に警告が出て `--render-test` が失敗します。
`SlowAction.exe --render-test` は仕様の数値と状態遷移を自動で確かめ、結果を `render-test-slow.log` と `slow-render*.png` に残します。

## 攻撃と動きの表現
- **斬り抜きの軌跡(スラッシュアーク)**: 斬り抜きの瞬間に、胸あたりを中心とした大きな三日月型の円弧を1本出します。
  先端が 0.10 秒で伸び切り、尾が 0.07 秒遅れて追いかけて細く消えます(実時間。ヒットストップ中は止まります)。
  手首の細かな動きには追従せず、出した場所に残ります。段と技で形と色が変わります。
  1段目は斜めの横薙ぎ(白〜水色)、2段目は逆向きの斜め切り返し(白〜水色)、3段目は大きく縦寄りの弧(黄金〜オレンジ)、
  強攻撃は体ごと回る水平の大弧(黄金)です。減速中は鮮やかなシアンへ寄せます。編集モードでは消えます。
  調整は `slow.Arc*`(太さ、明るさ、分割数、出すタイミング)。
- **攻撃の緩急**: 通常攻撃の再生倍率を振りの位相で変えます。振りかぶりは溜め(`ComboWindupScale`)、当たる瞬間の前後で一気に斬り抜き
  (`ComboSlashScale`)、振り終わりは緩めて残心を見せます(`ComboFollowScale`)。攻撃の長さと当たる瞬間は、この倍率の積分で決まるので、見た目と判定は一致します。
  当たりはクリップの当たる位置を通過した瞬間に出します。現在の値では、1段目が約0.23秒、2段目が約0.30秒です(2段目はクリップの区間が長いため)。
- **向き直り・踏み込み**: 攻撃の出だしは向きを `AttackTurnSeconds` かけて変え、瞬間にワープしません。踏み込みは速く出て、当たる直前にキュッと止まります(足元に砂ぼこり)。
- **残心**: 攻撃の終わりは `AttackFadeOutSeconds`(0.28秒)かけて構えを解きます。ダッシュで打ち切るときは短く解きます。
- **移動**: 速さで Idle→Run→Dash を混ぜる1Dブレンドツリー(`Locomotion`)です。攻撃・溜めの間は待機側へ寄せます。
- **体の傾き**: 旋回の内側へ最大 `BankMaxDegrees`(12度)傾け、攻撃・溜め・停止では起こします。ダッシュは `DashLeanDegrees`(6度)前へ傾けます。
  傾きは足元を中心にモデルの中で掛けるので、剣も一緒に傾き、コライダーは変わりません。
- **溜め**: 溜めの間は剣が微かに震え(`ChargeShakeMeters`)、周囲の光の粒が剣の握りへ吸い込まれます(`ChargeGatherPerFrame`、`ChargeGatherRadius`)。
  強攻撃が出せるようになった瞬間、剣先がキラッと光ります。

## 闘技場の質感

床・壁・障害物は `realistic-arena`(`shaders/surfaces/realisticArenaPS.hlsl`)で描きます。テクスチャは使わず、ワールド座標から石材の模様を作ります。

- **模様**: 床は2mの敷石、壁は横長のブロックを段ごとに半分ずらして積みます。目地は面取りした溝で、法線を傾けて凹凸に見せます。
  ブロックごとに色と粗さを少し変え、細かなノイズで表面のざらつきと汚れを足します。
- **接地の陰**: 壁や柱の根元(高さ1mほどまで)ほど暗く汚れ、環境光も届きにくくなります。
- **材質の差**: 素地の色はモデルの材質色(`scripts/generate-slow-action-models.sh`)で、床は暖かい灰色の石、壁は風化したコンクリート、
  障害物は暗い鉄混じりの石です。粗さ・金属度・ブロックの大きさ・風化の強さは `SetShaderFloat`(`roughness`、`metallic`、`tileScale`、`weathering`)で変えます。
  障害物は金属度があるので、空や太陽を鈍く映し、汚れた所は錆びて、角は磨かれて光ります。
- 照明はキャラや剣と同じ `RealisticLighting.hlsli`(GGX の鏡面反射、手続きの空の映り込み、ポアソンディスクの柔らかい影)です。

## 調整パネル (F4)

F4 で開閉する調整パネルです。ゲームを動かしたまま、手触りを詰められます。

- **時間の制御**: 一時停止・再開、停止中の「1フレーム進める」(剣閃や当たりを1フレームずつ確かめる)、時間の速さ(0.1x〜1.5x)。
  当たり判定(F1)・敵無敵(F2)・やり直し(R)もここから切り替えられます。
- **調整値**: `slowActionTuning.def` の全項目を見出しごとに並べます。検索欄でキー名を絞り込み、値を動かすと次のフレームから反映されます。
  既定値と違う項目は `*` が付き、「戻す」で既定値へ戻せます。
- **保存**: 「保存」は `assets/config/slow-gameplay.cfg` を、実行フォルダとソースフォルダの両方へ書きます。
  コメントと行の順は保ったまま、値だけを書き換えます。「ファイルから読み直す」「すべて既定値に戻す」もあります。
- **操作の扱い**: パネルを開くとマウスは画面から離れ、パネルの上にあるとき・文字入力中はゲームの操作を止めます。
  開いている間はマウスで視点は回りません(閉じた瞬間に視点が飛ばないよう、動かした量は捨てます)。
  F4 でも右上の「×」でも同じように閉じ、時間の制御(停止・速さ)は通常へ戻ります。やり直し・シーンを終えるときも同じです。
  編集モード(F3)と同時に開いていても、どちらかが開いている間はカーソルは自由なままで、両方閉じたときにゲーム用の捕捉へ戻ります。
